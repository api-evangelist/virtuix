# Virtuix

> Virtuix builds omnidirectional VR treadmills. Omni One is a consumer/enterprise full-body VR
> movement system with its own game store and a licensed Unity/Unreal developer SDK; Omni Arena is
> the location-based esports attraction for venues. Virtuix publishes no OpenAPI, no REST reference
> and no public HTTP API. Its one machine-callable surface is an anonymous UCP-conforming MCP
> agent-commerce endpoint on its own domain, and its developer platform is reachable only through a
> licensed game-engine SDK.

Generated by the API Evangelist enrichment pipeline on 2026-09-04 from documents fetched from
Virtuix hosts. Provider does not publish its own /llms.txt (docs.virtuix.com answers 200 with a
Docusaurus HTML shell for that path, as it does for every unknown path).

## Callable surfaces

- [UCP agent-commerce MCP endpoint](https://virtuix.com/api/ucp/mcp): JSON-RPC 2.0 over HTTP POST,
  MCP protocol 2025-06-18, UCP 2026-08-25. 13 tools, no authentication required for catalog, cart
  and checkout: get_checkout, create_checkout, update_checkout, complete_checkout, cancel_checkout,
  get_cart, create_cart, update_cart, cancel_cart, get_order, search_catalog, lookup_catalog,
  get_product. Prices are integer ISO 4217 minor units plus a currency code.
- [Legacy Storefront MCP endpoint](https://virtuix.com/api/mcp): DEPRECATED. Its own responses say
  it stops being served after 2026-08-31 and to migrate to /api/ucp/mcp. Still answering as of
  2026-09-04. 5 tools.
- [UCP discovery document](https://virtuix.com/.well-known/ucp.json): declares the dev.ucp.shopping
  service and the cart, checkout, fulfillment, discount, order, catalog.search and catalog.lookup
  capabilities.
